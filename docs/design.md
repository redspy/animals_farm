# 게임 설계 문서 (Design Doc)

## 상태: 미확정 (2026-09-03)

게임 장르·코어 루프·기술 스택·플랫폼이 아직 결정되지 않았다. 이 문서는 결정된 항목만 채우고, 미결정 항목은 "미확정"으로 남긴다 — 빈 문서를 억지로 채우면 Codex 문서 정합성 감사가 존재하지 않는 스펙을 근거로 코드를 지적하게 되므로, 정직한 미확정 표시가 원칙이다(`docs/agents/roles.md` §3).

## 1. 코어 루프
미확정.

## 2. 기술 스택 / 타깃 플랫폼
미확정.

## 3. 밸런스·경제 데이터 규칙
미확정. 확정 시 원칙: 수치는 코드에 흩뿌리지 않고 데이터 파일로 분리하고, 항목마다 유효범위(min/max)를 명시한다.

## 4. 세이브 데이터 스키마
미확정. 확정 시 원칙: 스키마에 버전 필드를 두고, 마이그레이션마다 역방향 손실 여부를 명시하며 구버전 로드 회귀 테스트를 남긴다.

## 5. 비주얼 가이드라인
미확정. 이 절이 채워지는 시점부터 `agy`(Gemini) 스크린샷 비주얼 패리티 리뷰가 필수 게이트로 승격된다.
